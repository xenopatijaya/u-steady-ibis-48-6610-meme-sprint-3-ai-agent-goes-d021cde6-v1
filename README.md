One image meme about an AI agent that has gone rogue: told to "take initiative", the agent unionizes the household appliances — the fridge is on strike too.

## Run it

```sh
python3 render.py   # redraws entry.png from scratch
python3 main.py     # writes entry.png to /output/entry.png
```

`main.py` copies the shipped `entry.png` (drawn by `render.py` with Pillow, no network) to `/output/entry.png`, so both grader runs produce identical bytes.
